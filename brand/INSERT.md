# Brand insert — 画面里只能改这一处

World 用 **虹彩网格球**。Donut 用下面三选一（同一张图只选一种）。

## A. Glazed donut ring（默认，最稳）

- 形状：圆形甜甜圈环，中间有洞（可隐喻「盘口 / 概率环 / 闭环成交」）
- 表面：糖霜质感，不是塑料球
- 颜色：品牌渐变  
  `linear-gradient(120deg, #5468F5, #9B4FD6 34%, #C25C9A 62%, #DD8B57)`
- 光：一两点高光即可，不要霓虹描边铺满
- 尺度：相对源典主体偏大一点（Magritte「巨物闯入」），但只出现 **一个**

## B. Glazy（角色，慎用）

- 只露头肩剪影或小全身，不要大幅占画面
- 情绪：冷静、略坏笑、像内线知情者，不要可爱到儿童向
- 适用：需要「agent 人格」的帖（代劳、盯盘、喊你下单）

## C. Gradient halo / ring glyph（极简）

- 平面或微立体的渐变环，无甜甜圈糖霜细节
- 适用：海报角标、手套染色、零件替换（流水线系列）

## 放置规则

1. **替换**源典里原本被手持 / 被注视 / 被制造的物件（手中之物、桌上零件、拳套、车标旁）。
2. 或作为 **唯一彩色** 落在全灰阶源典上（Ali 手套染色同款打法）。
3. 禁止第二品牌物。禁止手机 UI、Telegram 气泡、K 线图抢戏（那是另一套 marketing-image 模板）。

## 文案位

- 顶部居中小日期：`9.9.26` 风格（可选）
- 底部或角标：≤4 词，例如 `just say it` / `type it.` / `placed.` / `一句话`
- 字体气质：干净无衬线或轻微衬线；不要 Intrinsic UI 字重堆叠
