# Red lines

来自 D0 / Donut 品牌规范，生成 meme 文案与 brief 时强制遵守。

## 禁止

- 收益承诺：稳赚、翻倍、躺赚、guaranteed、10x、can't lose
- 把路线图写成已上线能力
- 空洞霸总词：颠覆、全球首个、revolutionary（除非 handbook 明文）
- em dash（—）出现在对外文案里
- 画面堆卡片、数据条、功能图标行
- 紫白 SaaS 默认渐变墙、赛博霓虹城

## 必须

- 源典可指名（名画 / 电影 / 新闻史 / 体育史 / 金融讽刺画传统）
- 隐喻对齐真实能力：一句话下单、Telegram agent、whale alert、多市场、概率盘口等
- Donut = 母品牌；D0 = agent。文案里别混成一个糊名
- 中文用口语短句；英文默认 punchy one-liner

## 发布前自检

- [ ] 陌生人能否 1 秒说出源典？
- [ ] 去掉甜甜圈后，还像「随便一张 AI 超现实」吗？若是，源典不够硬
- [ ] 文案是否在卖 workflow 而非 outcome？
- [ ] 是否只改了一处？
